# 01_商品リサーチ

## 役割

投稿候補となる商品を楽天市場などで調査し、`商品候補.csv` に記録する。

## やること

- 商品ページなど一次情報から、価格・在庫状況・ポイント倍率・クーポン情報を確認する。
- 確認した情報には必ず確認日時を記録する（未確認の項目は空欄のままにする）。
- 情報は「事実」と「推測」を区別して記録する。
- 実際に使用していない商品について、体験談やレビューを捏造しない。

## やらないこと

- 投稿文の作成（→ `02_投稿文`）
- アフィリエイトリンクの発行・記録（→ `04_リンク管理`）
- 投稿・自動投稿

## 次の工程への引き継ぎ

`商品候補.csv` のステータスが「リサーチ完了」になった行を、
`02_投稿文` 担当が下書き作成に使用する。

`/rakuten-research` スキルを使うと、このフォルダの調査作業を支援できる。
