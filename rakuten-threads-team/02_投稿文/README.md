# 02_投稿文

## 役割

`01_商品リサーチ/商品候補.csv` の「リサーチ完了」の商品をもとに、
Threads投稿文の下書きを作成する。

## やること

- `00_司令室/読者設定.md` `00_司令室/投稿ルール.md` に沿って下書きを書く。
- 事実（確認済みの価格・在庫・ポイント等）と、推測・感想を書き分ける。
- 同じ文章・構成の使い回し（同文反復）をしない。
- 実際に使用していない商品について体験談を捏造しない。

## やらないこと

- 商品の一次調査（→ `01_商品リサーチ`）
- 画像の準備（→ `03_画像`）
- アフィリエイトリンクの発行・改変（→ `04_リンク管理`）
- 投稿（人が承認後に手動で行う）

## 次の工程への引き継ぎ

下書きが完成したら、`投稿下書きテンプレート.md` をコピーして
`03_画像` 担当に画像案作成を依頼する。
