# 03_画像

## 役割

投稿下書きに合わせて使用する画像案を準備する。

## やること

- 自作の写真・図解、または利用許諾のある素材のみを使用する。
- 使用する画像の出典・ライセンスを `画像案テンプレート.md` に記録する。
- 商品の外観を誤解させるような加工はしない。

## やらないこと

- 商品の一次調査（→ `01_商品リサーチ`）
- 投稿文の作成（→ `02_投稿文`）
- 他人の画像・文章の無断転載

## 次の工程への引き継ぎ

画像案が準備できたら、`04_リンク管理` でリンク確認を行い、
そのあと `00_司令室/承認待ち` にまとめて提出する。
