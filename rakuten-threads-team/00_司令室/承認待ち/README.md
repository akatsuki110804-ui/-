# 承認待ち

ここは公開前の最終ゲートです。`04_リンク管理` までの工程を終えた投稿候補は、
すべてこのフォルダに置き、`_テンプレート_承認シート.md` をコピーして
1件ずつ人が確認します。

## 使い方

1. `_テンプレート_承認シート.md` をコピーし、`承認シート_投稿ID.md` のような
   名前で保存する。
2. 対象の投稿下書き・画像・リンク台帳の該当行を紐づけて記入する。
3. チェック項目をすべて確認し、担当者が最終判定（承認/差し戻し）を記入する。
4. 「承認」になったものだけを、人が手動でThreadsに投稿する。
5. 投稿後、`05_数値チェック/投稿実績.csv` に記録する。

## 注意

- 1項目でも確認が取れないものがあれば「差し戻し」とし、理由を記入して
  該当の担当役割（01〜04）に戻す。
- このフォルダにあるファイルを自動投稿ツールに接続しない。
