# 04_リンク管理

## 役割

楽天から発行されたアフィリエイトURLを、改変せずそのまま`リンク台帳.csv`に記録・管理する。

## やること

- 楽天アフィリエイトで発行されたURLを、発行された形のまま台帳に記録する。
- リンク先が正しい商品ページであることを確認し、確認日時を記録する。
- リンクの有効/無効の状態を管理する。

## やらないこと（重要）

- アフィリエイトURLの自動生成・短縮・パラメータの改変は行わない。
- 発行元（楽天）以外で作られたURLを使用しない。
- 返信欄やDMへのリンク送付は行わない（本文内のみ）。

## 次の工程への引き継ぎ

リンク確認が完了したら、投稿下書き・画像とあわせて
`00_司令室/承認待ち` に提出する。
