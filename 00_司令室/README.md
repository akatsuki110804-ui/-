# 00_司令室

このフォルダは運用全体の司令室です。読者設定・投稿ルールを管理し、
すべての投稿候補が公開される前の最終チェックポイント（承認待ち）を担います。

## このフォルダにあるもの

- `読者設定.md` — 想定読者（ペルソナ）の定義。投稿文・画像作成の判断基準になる。
- `投稿ルール.md` — 投稿頻度・トーン・禁止表現などの運用ルール。
- `承認待ち/` — 各役割の成果物が最終的に集まる場所。ここで人が確認するまで公開しない。

## 運用フロー全体図

```
01_商品リサーチ → 02_投稿文 → 03_画像 → 04_リンク管理 → 00_司令室/承認待ち → 人が確認 → 手動投稿 → 05_数値チェック
```

## 司令室担当の役割

- 読者設定・投稿ルールを最新に保つ（変更したら更新日・更新者を記録）。
- `承認待ち` に集まった投稿候補について、承認シートの全項目を確認する。
- 1項目でも未確認・不明点があれば「差し戻し」とし、公開しない。
- 自動投稿ツール・予約投稿の設定は行わない。投稿は必ず人が手動で行う。

共通ルールの詳細はリポジトリ直下の `CLAUDE.md` を参照。
