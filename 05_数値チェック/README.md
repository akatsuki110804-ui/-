# 05_数値チェック

## 役割

人が手動で公開した投稿について、数値を記録し振り返る。

## やること

- 投稿後、`投稿実績.csv` にインプレッション・いいね・リポスト・返信数などを記録する。
- 記録日時と記録者を必ず残す。
- 良かった点・改善点を「気づき」として記録し、次回の商品リサーチ・投稿文作成に活かす。

## やらないこと

- 投稿・自動投稿（このフォルダは公開後の記録専用）
- 数値の推測での水増し・改ざん

## 使い方の流れ

`00_司令室/承認待ち` で承認された投稿を人が手動で投稿した後、
一定期間（例: 24時間後、1週間後など）に数値を確認し、このフォルダに記録する。
